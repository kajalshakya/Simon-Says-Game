# Simon Says Game

## About
Simon Says Game is a memory-based game built using HTML, CSS, and JavaScript. The player must remember and repeat the sequence of colors displayed by the game.

## Features
- Interactive color buttons
- Increasing difficulty with each level
- Game Over message for incorrect sequences
- High score tracking during the current session

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
```text
simon-game/
├── index.html
├── style.css
├── app.js
└── README.md
```

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Press any key to start playing.
